JRXDY GAMES — updated website with TikTok tab

Replace the files in your existing GitHub repository with these updated files:
- index.html
- style.css
- script.js

On GitHub: open each file, choose Edit, replace its contents, then Commit changes. You can also upload the three files and choose to replace existing files.

The new TikTok tab accepts a public TikTok VIDEO URL and tries to display TikTok's official video embed inside the JRXDY page. TikTok may refuse to embed some videos or restrict access. This does not embed the entire TikTok app or bypass network restrictions.

To add games later, edit the `games` array near the top of script.js. Use game links/files you own, have permission to share, or that officially allow embedding.
